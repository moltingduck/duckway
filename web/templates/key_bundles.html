Key bundles

Named sets of keys, one per service, that you assign to clients in one step.

How bundles work

A bundle holds one entry per service. Each entry points at an API key or at a per-request rotation pool. Assign a bundle to a client and that client receives one phantom token for every entry. Changing an entry's key or pool updates the phantom tokens of every assigned client. A phantom token you created by hand for the same service on that client takes priority and is not replaced.
