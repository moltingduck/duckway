Control Channels

A Control Channel (CC) binds a bot token to a service-specific scope (e.g. a Discord category). Clients assigned to a CC each get a home channel auto-provisioned under that scope, and their agent gets an MCP/skill bundle written by duckway sync. Bot token = security boundary — clients sharing one CC can interact with each other’s channels.
