How canary tokens work

Canary tokens are enabled by default for new clients. On registration Duckway creates decoy credentials; if one is used, you get an email.

API tokens are real tripwire credentials issued by canarytokens.org. Local decoy files embed a DNS canary hostname that alerts when resolved.

Decoys sit at realistic paths with .bak suffixes or non-standard locations. They are not in keys.env, so agents use the real phantom tokens and ignore them.
