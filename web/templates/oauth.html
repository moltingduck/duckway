Refreshable Tokens

API keys with refresh tokens are auto-refreshed by the server before expiry. Works for OAuth-based services that return an access token plus refresh token. Stored in the same API Keys table — clients assign them like normal keys.

Delivery on the client: Anthropic refreshable tokens are written as a file at ~/.claude/.credentials.json (with companion ~/.claude.json and ~/.claude/settings.json) — not as the ANTHROPIC_API_KEY environment variable. Claude Code reads the credentials file directly. Other refreshable services follow the same file-based pattern when supported.

Upload formats differ by service:
  • Claude Code: paste ~/.claude/.credentials.json; Duckway reads claudeAiOauth.accessToken, refreshToken, expiresAt, subscriptionType, rateLimitTier, and scopes.
  • Generic OAuth: paste a token response like {"access_token":"...","refresh_token":"...","expires_in":3600}, then set the token endpoint.
  • Manual entry: paste the access token and refresh token into their fields directly when the provider does not expose a JSON file.
