Set up a GitHub App for minting tokens

  1. Register a GitHub App in your personal account at Personal account settings, or in an organization at https://github.com/organizations/ORG/settings/apps/new (replace ORG with its name).
  2. Under Repository permissions, grant Contents: read-only for clone and pull. Grant Contents: read and write only if this credential needs to push. Add other permissions only when the client needs those GitHub features.
  3. Save the App, then install it and grant access to the repositories Duckway should reach. The installation must include the target repository.
  4. Enter the App ID from the App settings page. Use App ID, not Client ID.
  5. Enter the Installation ID from the App's Install App page: choose Configure for the personal or organization installation. Its URL ends in /settings/installations/ID; the final number is the Installation ID. You can also get it from GitHub's List installations API.
  6. On the App settings page, create a key under Private keys. Paste the complete PEM contents, including the BEGIN and END lines, into the private key field.

Setup URL is an optional redirect after installation; it is not a URL to enter in Duckway. A private key is a sensitive, long-lived credential: keep it secret and rotate or revoke it if exposed. Duckway stores it server-side and mints short-lived, scoped installation tokens.
