Plugins

Register a plugin source, check for a release, and explicitly publish it before clients install it with duckway plugin install NAME.

Disabling a plugin blocks future server distribution. It does not stop or remove plugins already installed on clients. Client versions appear only after clients report them; this page does not track running processes.

Register a plugin source

Only publish a source you trust: plugins run native code on clients. Registration checks the manifest. Publishing downloads every declared artifact and verifies its size and SHA-256 before enabling distribution. These integrity checks do not assess whether the code is safe.

The source URL is saved and shown to administrators. Use a public release URL without credentials, query parameters, or fragments. Checks use this same saved source. The server checks automatically every 6 hours by default; publication and client updates remain explicit actions.
