Notifications

Where Duckway sends approval alerts. Each channel can be switched off without deleting it.

When alerts are sent

Every enabled channel gets one message when an agent request needs approval and none is on file:

  • a proxied API call through a phantom token that requires approval;
  • a key loan (LOAN) for a binding that requires approval.

The message names the approval ID, client, service, method and path. Nothing else is sent to these channels. Canary alerts use the canary email instead. Telegram and Discord bot channels also take Approve / Reject replies; webhooks are send-only.

Disabling a channel stops alerts to it immediately. Reply listeners for a Telegram or Discord bot channel that was already running keep listening until the server restarts.
