3 Delivery

Who talks to the upstream and which requests Duckway can inspect.

MITM (man-in-the-middle) means the gateway terminates TLS for this host, so it can check ACL rules, ask for approval and log each request. Use proxy by default. loan_proxy lets the sidecar cache the token and skip the gateway for high-bandwidth services, with coarser approval and audit.
Off by default. Turn it on for APIs that put a slash inside one path segment, for example GitLab project paths such as /projects/group%2Fproject. Access rules then see %2F as part of its segment, so a rule for /projects/* matches, but a rule written as /projects/group/project will not match such a request. A segment that mixes %2F with a literal % is refused. %5C, an encoded ? or # (%3F, %23) and control characters in a path are always refused.
