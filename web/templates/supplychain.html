Supply Chain

Package Manager Hardening

On every duckway sync, the client writes a managed block into each agent's package-manager rc file (~/.npmrc, ~/.yarnrc.yml, ~/.config/uv/uv.toml, ~/.config/go/env, …) that disables pre/post-install scripts and refuses packages published within the cooldown window. This blocks the two highest-leverage supply-chain vectors: malicious lifecycle scripts (npm preinstall/postinstall, Yarn scripts, etc.) and freshly-published compromised versions that auto-install before the registry yanks them. User content outside the managed block is preserved; rolling-date cutoffs refresh on every sync. Mitigations default to all-on. Managers with no rc-file gate are listed for transparency — see their Notes for alternatives.
