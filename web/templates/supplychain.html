Supply chain

Harden package managers on every client: block install scripts and brand-new package versions.

How this works

On every duckway sync, the client writes a managed block into each agent's package-manager config file (~/.npmrc, ~/.yarnrc.yml, ~/.config/uv/uv.toml, ~/.config/go/env and similar). The block disables pre/post-install scripts and refuses packages published within the cooldown window.

This blocks the two highest-leverage supply-chain vectors: malicious lifecycle scripts (npm preinstall/postinstall, Yarn scripts) and freshly published compromised versions that auto-install before the registry yanks them.

Content outside the managed block is preserved. Rolling-date cutoffs refresh on every sync. Every mitigation is on by default.

Minimum package age

Whole days, 1 to 365. Applies to every enabled mitigation. Default: 3.
