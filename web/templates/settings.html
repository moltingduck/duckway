Settings

Gateway Configuration

Configure how clients connect to the Duckway gateway. These values are used in setup commands and client config.

The URL agents use to reach the gateway. Used in install commands and client init. Required in split mode (admin panel does not serve /install.sh). Leave empty in combined mode to fall back to the admin panel URL.
Suggested port for duckway proxy on client machines. Default: 18080.
If an admin doesn't reply within this window, the request is marked ignored (not rejected). Default: 60.

Architecture

ProfileContainersPorts
combined duckway-server 127.0.0.1:8080 (dev)
split duckway-admin + duckway-gateway 127.0.0.1:9091 + 127.0.0.1:8080 (dev)
prod duckway-server none — reverse proxy or Tailscale
prod-split duckway-admin + duckway-gateway none — reverse proxy or Tailscale
tailscale-combined duckway-server + Tailscale sidecar :80 inside tailnet
tailscale duckway-admin + duckway-gateway + 2 Tailscale sidecars :80 each inside tailnet

In split mode, agents only access the gateway. Admin panel runs on a separate node protected by Tailscale ACL. Use ./scripts/prod.sh to start production profiles.
