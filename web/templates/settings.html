Gateway

Where clients connect. These values are used in install commands and client config, and reach clients on their next sync.

The URL agents use to reach the gateway. Required in split mode, where the admin panel does not serve /install.sh. Leave empty in combined mode to fall back to the admin panel URL.

Suggested port for duckway proxy on client machines (1024 to 65535). Default: 18080.

Request log rows older than this are deleted automatically (1 to 3650 days). Default: 90.

Approvals

If nobody answers an approval request within this window it is marked ignored (not rejected).

Whole minutes from 1 to 10080 (7 days). Default: 60.

Admin password

Changes the password for the account you are signed in with. Every other signed-in session is signed out when you change it, so each must sign in again with the new password. This session stays signed in.

At least 12 characters.

Agent statusline

A shell script that every agent's duckway sync installs at ~/.duckway/statusline.sh and wires into ~/.claude/settings.json (statusLine.command), backing up any existing file to .duckway-backup. Leave it empty to disable and let agents keep their own statusline. Claude Code pipes a JSON payload to the script on stdin and shows the first line it prints. See the Claude Code statusline docs.
